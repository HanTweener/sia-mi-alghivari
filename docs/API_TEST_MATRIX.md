Notasi mengikuti kontrak: M Master, A Akademik, D Data Entry, G guru mapel aktif, W wali kelas aktif, P principal, O orang tua/wali; MA berarti M atau A. D bukan singkatan hak hapus. Semua memakai sesi first-party; H/M = halaman/form Inertia, J = JSON pendukung, F = file privat, B = authorization broadcaster. Role rangkap diuji dengan grant yang cocok; Master tetap tidak melewati audit, status final atau approval principal.

Setup yang direncanakan: dua kelas/mapel, guru berbeda dan guru dengan role rangkap, dua wali dengan anak berbeda, dua periode, assignment aktif/inactive, delegasi aktif/dicabut, policy dan rapor beberapa versi. Waktu/identitas/fixture sintetis deterministik, DB target dan akun runtime yang benar, koneksi independen untuk race. Dev/CI/demo terpisah; tidak menyerang demo aktif atau menganggap simulasi [prototipe memori](support/facelift-v2/README.md) sebagai tes server.

Setiap mutasi existing mengikuti expected_version yang ditetapkan API, termasuk parent assessment/session/user/student yang relevan. Create tidak mendapat version objek baru fiktif; server mengunci parent dan memeriksa grant/state/unique saat commit. Untuk baris TERBUKA, assertion awal adalah jalur belum diaktifkan/bypass ditolak; expected positif setelah keputusan pemilik ditambahkan tanpa menebak aturan.

D-25 menggantikan D-23/D-24: password sementara emailed/forced change dan OTP email Fouladgar. Email langsung verified oleh Master; modal pilihan sesi setelah password tersimpan wajib, reset login biasa/profil current device tetap login. - **Ketidakpastian dan replay:** duplicate command boleh berakhir stale/state conflict, bukan wajib sukses identik. Correlation request_id bukan dedup receipt; tidak menguji Idempotency-Key generik yang tidak dirancang. Assertion mencakup row bisnis/audit/inbox, bukan status respons saja. BF-01/07/08 dan CT-06 menjadi rujukan.
- **Deadline/limit:** konfigurasi finite timeout/batch/upload/rate belum dipilih. Sesudah disepakati, uji tepat di bawah/pada/melewati batas dan Retry-After bila tersedia; tidak menciptakan angka default baru. Timeout sesudah commit dibedakan dari rollback sebelum commit.
- **Async:** N-T pada NOTIFICATION_TEST_PLAN menguji gap commit-sebelum-enqueue, worker/Reverb mati, job replay, out-of-order hint dan catch-up berizin. Tidak ada exactly-once atau klaim bahwa retry dapat memulihkan job yang tidak pernah terantre.
- **Proyeksi/cache:** baca berizin dan cache privat diuji sesudah role/relasi/delegasi dicabut; byte/hint yang telah disampaikan tidak dapat ditarik kembali. Origin bukan otorisasi; proyek lain tidak mendapat CORS terbuka. Middleware broadcaster mengikuti SES/API, bukan asumsi CSRF default.
- **N/A core:** JWT audience/expiry, OAuth provider, webhook signature/replay, pemasaran opt-out dan multi-tenant tidak dipakai. Isolasi pengguna/anak/kelas serta cookie/session/channel tetap wajib. N/A tidak berlaku bagi sisa Q6/visual Q7 atau lifecycle yang belum selesai.
