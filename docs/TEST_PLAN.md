## 1. Risks and environments

- Risiko tertinggi: bocor data siswa/credential, eskalasi role, nilai salah, audit/inbox tidak atomik, histori rusak, approval/apply tidak sah dan file privat terbuka. Scope izin tetap [matriks](ROLE_PERMISSION_MATRIX.md)/[policy](RESOURCE_ACCESS_POLICY.md), bukan definisi baru pada tes.
- Lokal dan CI disposable mengikuti ENVIRONMENT_SPEC, engine MySQL target jika DB-001 diterima, akun migrasi terpisah dari runtime. Fixture FIX-01..12 pada TEST_DATA_PLAN; jangan menggunakan data nyata, demo aktif atau endpoint publik untuk failure/load/destructive test.
- Usulan browser awal: Chromium untuk E2E CI, smoke Firefox/WebKit pada alur inti sebelum rilis; versi/browser OS nyata dicatat saat eksekusi. Target viewport AC-X03:360×800 dan1440×900; zoom/reflow/keyboard dan NVDA dengan browser Windows yang kompatibel diusulkan untuk manual assistive check. Matriks support final dan perangkat ponsel riil belum dipilih; emulasi viewport bukan bukti perangkat nyata.
- Akun Master, Akademik, Data Entry, teacher mapel/homeroom, principal, guardian, guest/inactive dan role rangkap tersedia sebagai fixture sintetis tanpa credential dalam dokumen. Login lokal, tidak ada registrasi publik/provider.
- Sebelum tiap run: verifikasi target/manifest fixture, versi artefak, clock/locale, database bersih, storage/queue/sesi terisolasi. Pada race gunakan dua koneksi independen dengan sinkronisasi, bukan simulasi sequential atau satu transaksi test.

## 3. Quality domains

Correctness: hitungan diperiksa dengan oracle manual/rasional independen; state, row, constraint, version, snapshot, checksum file, audit actor dan inbox recipient diperiksa sebelum/sesudah. Test doubles membantu failure injection, bukan menggantikan bukti engine/worker/WSS nyata.

Accessibility: target WCAG2.2AA, keyboard tanpa trap, fokus setelah modal/error, label field/tabel, pesan selain warna, zoom/reflow dan pembacaan assistive. Gunakan SCR-01..11/SX/DV pada spesifikasi layar; prototipe hanya referensi dan tidak memberi PASS.

Cakup current grants pada list/count/detail/write/file/job/channel, session/CSRF/origin dan revoke race. Bypass screenshot/tombol tersembunyi tidak membuktikan server. Provider/JWT/multitenant N/A dengan alasan scope, bukan penghapusan IDOR sesama sekolah.

Performance: T-20 mengukur distribusi fixture, query count/plan, latency persentil, lock/koneksi, CPU/memori/disk dengan versi runtime dan host tercatat. Metode, angka pilot serta hipotesis mengikuti [PERFORMANCE_BUDGET](PERFORMANCE_BUDGET.md), [LOAD_TEST_PLAN](LOAD_TEST_PLAN.md) dan [SLO_SLI](SLO_SLI.md); belum disetujui atau terukur. Migration/recovery/observability: T-19 dan DBV/BF kanonis; periksa data/files/jobs konsisten, health/smoke tidak hanya port terbuka. Metrik proposed/trace teredaksi, tidak menambah monitoring stack/dependency khusus tanpa kebutuhan.
