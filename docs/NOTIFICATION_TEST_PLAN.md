Batas yang diuji: mutasi berizin → transaksi bisnis+audit per objek+inbox → commit → enqueue database queue → worker → Reverb → Echo → refetch HTTP inbox/count terkini. Scope satu sekolah dengan beberapa pengguna/anak/kelas; bukan tenant A/B. Seluruh fixture sintetis dan environment terisolasi; fault/load tidak diarahkan ke demo aktif, Tunnel publik atau akun sekolah nyata.

Gunakan DB target dengan grant runtime, connection terpisah dan barrier terkontrol untuk race/commit; waktu dibekukan untuk read_at/expiry. Mock/stub membantu kegagalan deterministik, tetapi klaim integrasi worker/Reverb/Echo kelak memerlukan layanan uji nyata. Tidak membuat server atau menjalankan pengiriman pada tahap rencana ini.
